## Metodologias

| Área | Metodologias e práticas |
| --- | --- |
| Processo ágil | Scrum e Kanban; refinamento de histórias, critérios de aceite e Definition of Done |
| Estratégia de testes | Shift-Left Testing; pirâmide de testes (unitário, API, UI/E2E); testes baseados em risco |
| Abordagens orientadas a testes | TDD (Red-Green-Refactor); BDD com Gherkin (Given-When-Then); ATDD; DDD |
| Técnicas de design de testes | Partição de equivalência; análise de valor limite; tabela de decisão; transição de estados |
| Automação | Page Object Model; data-driven testing; testes independentes e repetíveis; separação entre camadas de UI e API |
| CI/CD e Continuous Testing | Execução automatizada em pipeline (GitHub Actions); quality gates; relatórios de execução |
| Análise de qualidade | Root Cause Analysis (5 Porquês); gestão de defeitos; rastreabilidade requisito-teste; métricas (cobertura, taxa de defeitos, testes instáveis) |

**QA Jr. at Accenture · Test Automation (API and UI) · Recife, Brazil**

I'm an early-career QA working on test automation, and a student of Information Systems Analysis and Development at CESAR School. I like investigating why a test fails, not just reporting that it failed: reproduce it, isolate the cause and document it with evidence.

- **Focus:** UI and API test automation, BDD
- **Practices:** smoke, sanity, regression, UAT, exploratory, E2E and root cause analysis
- **Daily use:** Tricentis TOSCA, Karate DSL, Cypress, Cucumber/Gherkin, Postman, Git
- **Learning:** Playwright, SAP, Java, JavaScript/TypeScript, GitHub Actions (CI)

**Methodologies**

- **Agile process:** Scrum, Kanban, story refinement, acceptance criteria, Definition of Done
- **Test strategy:** Shift-Left Testing, test pyramid (unit, API, UI/E2E), risk-based testing
- **Test-driven approaches:** TDD (Red-Green-Refactor), BDD with Gherkin (Given-When-Then), ATDD, DDD
- **Test design techniques:** equivalence partitioning, boundary value analysis, decision tables, state transition
- **Automation:** Page Object Model, data-driven testing, independent and repeatable tests, separation of UI and API layers
- **CI/CD and Continuous Testing:** automated pipeline execution (GitHub Actions), quality gates, execution reports
- **Quality analysis:** Root Cause Analysis (5 Whys), defect management, requirement-to-test traceability, metrics (coverage, defect rate, flaky tests)

**Background:** administrative roles working with Power BI, Excel automation and process digitization; joined Accenture after completing the QA Academy
